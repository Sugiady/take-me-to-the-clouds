# My Common Traps 🛠️

_Last updated: 2026-10-02_

This is the personalized error corner for **Take Me to the Clouds**.

> Note: the repository is public. “Private” here means personal-to-the-student, not secret.

## Active traps

### 1) 9,500 ft MSL is still below the Class E 10,000-ft switch
**Trap:** seeing “9,500” and jumping early to 5-111.  
**Correct:** Class E below 10,000 ft MSL uses **3-152**. At **10,000 ft MSL or above**, use **5-111**.

Memory hook:
> **9999 → 3-152; 10000 → 5-111.**

### 2) What does the “5” in 5-111 mean?
**5 = 5 statute miles flight visibility.**

Then:
- 1,000 ft below clouds
- 1,000 ft above clouds
- 1 statute mile horizontal

### 3) Ceiling
Only the **lowest BKN / OVC / VV** layer counts as the ceiling.  
FEW and SCT do not.

Memory hook:
> **BOV 才封顶.**

### 4) Gust factor
**gust factor = gust speed − sustained wind speed**

Example: 14G23 → gust factor = 9 kt.

### 5) Zulu time
Zulu = **UTC**, not automatically local time.  
Local conversion requires location + date + daylight-saving status.

### 6) Airspace altitude references
- Class B/C sector labels: normally **MSL**
- Class E 700/1,200-style floors: usually discussed in **AGL**
- Magenta dashed: Class E from **surface**
- Magenta vignette: Class E floor usually **700 ft AGL**

## Retired / improving traps
- Confusing “aileron neutral” with “wings level.”  
  The control returns near neutral after bank is established; the airplane can remain banked.
- Treating stall as “airspeed too low.”  
  The direct cause is exceeding **critical AoA**.

## Rule
Whenever a mistake repeats twice, add a new targeted randomized question to the web trainer.

> Regulatory details should always be checked against current FAA material before real flight planning.
