# Lesson Notes — Airspace & VFR Weather Minimums

_Last updated: 2026-10-02_

## 1. Class B: the upside-down wedding cake

Class B surrounds the busiest airports and is **individually tailored**. Its layered geometry is designed to contain published instrument procedures after aircraft enter the Class B airspace.

Why does the floor usually rise farther from the airport?

- Near the primary airport, arriving and departing traffic must be protected down toward the surface.
- Farther away, those same traffic flows are usually still higher.
- Therefore an outer Class B shelf can begin higher and leave lower airspace beneath it available to other traffic that does not enter Class B.

This is a useful mental model, not a substitute for reading the actual sectional: real Class B shapes are not perfect circles or identical cakes.

## 2. Reading Class B / C altitude labels

A label such as:

**100 / 40**

means:
- ceiling = **10,000 ft MSL**
- floor = **4,000 ft MSL**

A label such as:

**80 / SFC**

means:
- ceiling = **8,000 ft MSL**
- floor = **surface**

Memory hook:
> **Top = ceiling; bottom = floor; ×100 ft; B/C → MSL.**

## 3. What is above Class B?

A typical Class B may top out around **10,000 ft MSL**. Class A generally begins at **18,000 ft MSL**, so Class B does **not** normally connect directly to Class A.

A useful simplified vertical picture is:

**Class B → Class E → Class A (from 18,000 ft MSL)**

Class A operations are generally IFR unless otherwise authorized.

## 4. Class E chart cues

- **Dashed magenta**: Class E surface area.
- **Magenta vignette**: Class E floor at **700 ft AGL**.
- A blue vignette is used for controlled-airspace floors other than 700 ft where they abut Class G; 1,200 ft AGL is a common case.

Memory hook:
> **Magenta gradient = E still hanging; dashed magenta = E has landed.**

## 5. VFR weather-minimum patterns

### Class B
**3 SM + clear of clouds**

### Class C / D / Class E below 10,000 ft MSL
**3-152**
- 3 SM visibility
- 500 ft below
- 1,000 ft above
- 2,000 ft horizontal

### Class E at or above 10,000 ft MSL
**5-111**
- 5 SM visibility
- 1,000 ft below
- 1,000 ft above
- 1 statute mile horizontal

### Class G at or below 1,200 ft AGL
For fixed-wing aircraft, the usual Part 91 pattern is:
- Day: **1 SM + clear of clouds**
- Night: **3 SM + 500 / 1,000 / 2,000**

There are regulatory exceptions and additional Class G altitude bands; consult the current regulation before real flight planning.

## 6. Current targeted memory traps

- **9,500 ft MSL Class E → still 3-152.**
- **10,000 ft MSL Class E → switch to 5-111.**
- **The 5 in 5-111 means 5 SM visibility.**
